## English

**PdfOperations 1.0.0: portable for Windows x64**

Work with PDFs, images and office documents: conversion, OCR, splitting, merging, searching and text replacement. The interface supports English and Polish.

### Download and run

1. Download **`PdfOperations-1.0.0-win-x64-portable.zip`** below.
2. Extract the **entire ZIP** to a new folder you can write to.
3. Run **`PdfOperations.exe`** in the top-level folder. Keep `current`, `Update.exe` and `.portable` beside it.

**Only the application ZIP is needed.** There is no separate installer. .NET 10 Desktop Runtime and the required Visual C++ libraries are included; no separate installation or administrator rights are needed for normal use. Windows security checks and organizational restrictions still apply.

Microsoft Word is required only for **DOCX to PDF (Word)**. Otherwise, use the bundled LibreOffice. Before the first PDF-to-DOCX conversion, the app asks you to accept the bundled Visual C++ library terms.

### Updates and other assets

In **About**, choose **Check for updates → Download update**. Once ready, finish conversions, close other windows of the same copy and select **Restart and update**. Downloading can be cancelled. The first update may download a full package; later updates can use differential packages when available. Keep personal documents outside `current`.

Older portable copies without Velopack must be replaced manually once by extracting this ZIP to a new folder. Another package numbered 1.0.0 is not detected as a newer version.

- `*.nupkg` and `releases.win.json`: updater files; no manual download is needed.
- `*-third-party-sources.zip`: third-party source code, not required to run the app.
- `SHA256SUMS.txt`: checksums for verifying the release assets.

## Polski

**PdfOperations 1.0.0: wersja przenośna dla Windows x64**

Praca z plikami PDF, obrazami i dokumentami biurowymi: konwersja, OCR, dzielenie, łączenie, wyszukiwanie i zamiana tekstu. Interfejs jest dostępny po polsku i angielsku.

### Pobieranie i uruchomienie

1. Pobierz poniżej **`PdfOperations-1.0.0-win-x64-portable.zip`**.
2. Rozpakuj **cały ZIP** do nowego folderu, w którym masz prawo zapisu.
3. Uruchom **`PdfOperations.exe`** z głównego folderu. Zachowaj obok niego `current`, `Update.exe` i `.portable`.

**Wystarczy sam ZIP z aplikacją.** Nie ma osobnego instalatora. .NET 10 Desktop Runtime i wymagane biblioteki Visual C++ są już dołączone; do zwykłego korzystania nie potrzeba osobnej instalacji ani uprawnień administratora. Nadal obowiązują zabezpieczenia Windows i ograniczenia organizacji.

Microsoft Word jest potrzebny tylko do opcji **DOCX do PDF (Word)**. W pozostałych przypadkach można skorzystać z dołączonego LibreOffice. Przed pierwszą konwersją PDF na DOCX program pyta o akceptację warunków dołączonej biblioteki Visual C++.

### Aktualizacje i pozostałe pliki

W widoku **O programie** wybierz **Sprawdź aktualizacje → Pobierz aktualizację**. Gdy aktualizacja będzie gotowa, zakończ konwersje, zamknij pozostałe okna tej samej kopii i kliknij **Uruchom ponownie i zaktualizuj**. Pobieranie można anulować. Pierwsza aktualizacja może pobrać pełną paczkę; kolejne mogą korzystać z pakietów różnicowych, jeśli zostaną udostępnione. Własne dokumenty przechowuj poza `current`.

Starsze kopie portable bez Velopack trzeba jednorazowo zastąpić ręcznie, rozpakowując ten ZIP do nowego folderu. Inna paczka oznaczona jako 1.0.0 nie jest wykrywana jako nowsza wersja.

- `*.nupkg` i `releases.win.json`: pliki mechanizmu aktualizacji; nie trzeba ich pobierać ręcznie.
- `*-third-party-sources.zip`: źródła składników zewnętrznych, niepotrzebne do uruchomienia programu.
- `SHA256SUMS.txt`: sumy kontrolne do sprawdzenia plików wydania.
